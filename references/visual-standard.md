# 手作旅行剪贴簿：视觉标准

本标准适用于用户要求的纸本手帐风格。用户提供新参考时，以新的明确要求为准；不要让“高级感”“艺术感”等抽象形容词覆盖已经选定的手作语言。摄影相册与其他明确指定的媒介另行选择。

## 手作语言的组成

参考的作用是确定材料和观看方式，不是复制别人的照片、文字或完整版式。以下构图可按素材选择和组合：

| 构图类型 | 可迁移的构图判断 |
| --- | --- |
| 雪山与小镇的撕边主视觉 | 摄影可以铺满纸页；另一张照片或纸面沿不规则撕边接入。大字像写在照片上，旁注对应具体景物。 |
| 人像与城市的纸片页 | 人像保留原貌，底下有不同颜色纸片；建筑、食物等异形贴纸跨越照片和纸片，不只是角落图标。 |
| 收据叠层与异形开窗 | 旅行留下的实物或文字碎片成为主要材料；纸窗露出风景，外面的手写标题、注释与里面的地标发生关系。 |
| 笔记、照片与侧边折页 | 有较完整的手写观察、圈画和具体说明；小幅照片与纸条交叠，展开的附页或口袋要有可信的遮蔽和折痕。 |
| 风景与胶片、圆窗组合 | 不同大小和形状的照片形成节奏，允许局部重叠；票据、地图与照片互相呼应，背景不是统一卡片模板。 |
| 登山路线采集页 | 手绘路线串起照片、地点标签和物件，行李纸签有孔与线；线条真的指向沿途对象。 |
| 衣物与物件贴纸页 | 把物件从照片里提出来，边缘完整、尺度有主次，再用手写标签和箭头说明；同一页不需要大风景图。 |

不要为模仿“真实感”编造收据、消费金额、日期、轨迹或同行人。缺少用户实物时，使用明确属于主题创作的观察纸条、地点签和色彩采集卡；只写已知信息。

## 成稿应该像一本用过的本子

- **材料有区别。** 底纸、薄纸条、照片纸、胶片边和半透明胶带分别处理。边缘是不规则细碎毛边；影子跟叠放关系走，不能每层都同样厚重。纸纹只作用于纸面，不给原摄影套仿旧滤镜。
- **文字留下观察。** 标题、较完整的手写记录、照片旁的小字分工明确。写能从素材看见的细节，例如桥的红色、缆车的木窗框、窗框的质地；观察之后允许克制的比喻与余韵，按 [写作标准](writing.md) 执行；避免全本都是两行泛泛的旅行抒情句。文字独立排版、逐字可读，不让图像模型写中文。
- **贴纸改变构图。** 先挑适合分离的摩天轮、交通工具、建筑、植物、动物等主体；让它跨纸边、补足路线或成为采集页主角。优先完整主体，动物与人物不能呈现突兀的截断肢体。不能把换了四个地点名字的通用图标称为专属贴纸。
- **照片仍有现场感。** 保留自然光、人物、地标关系与细节。人物不为“漂亮”而替换脸或生成陌生同行人。原摄影和生成的物件衍生创作分开记录；重绘不是逐像素抠图。
- **跨页有关系。** 两页通过地点、颜色或材料相连，分别承担不同观看方式。电脑显示摊开的双页纸本，手机显示同一页图的单页；输出页图与阅读页图同源。

## 整本的节奏与检查

排版前用一句话记录每页的主材料、贴纸用途和文字内容。一本较长的样册应有叠层照片、开窗、路线或索引、物件采集、笔记与口袋等不同结构，按实际素材选用。不要把相同的大图位置、小图位置和两行文字连续复用，页数增加不能变成复制模板。

出图后先看整本缩略总览，再看每一组跨页和每张原尺寸页图。逐项判断：

1. 去掉地名后，是否仍能从景物与物件看出这页的地方？
2. 去掉文字后，是否仍有纸片、剪贴与手作层次？如果只剩照片网格，重做。
3. 贴纸是否来自这段素材，是否跨层或承担采集与路线作用？检查 alpha 和毛发、栏杆等难边缘。
4. 手写内容是否具体、可读，箭头是否有指向，是否出现孤字断行、照片主体被压住或正文被纸片挡住？
5. 整本是否有构图变化，照片重复使用是否有近景观察、索引或昼夜对照的理由？
6. 阅读器是否保留纸本双页，导出是否与页面一致？奇数页最后一页应独立收尾，不能出现错误的下一页页码。

如果用户认为“手帐不像手帐”，先修复材料、剪贴与记录，不能只增加照片或改网站外壳。技术检查通过与用户审美验收分别说明。
