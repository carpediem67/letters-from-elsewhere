# 写作：从看见的细节，到一封短短的信

默认是有文学感的中文手帐旁注。用户指定纪实、活泼、极简或其他语言时，以用户选择为准；不让文案反过来支配照片。

## 写什么

每页先找一个真实可见的细节：影子落在台阶、红桥横过蓝天、卷发被风吹开、木车窗、岩层里的光。再让它与纸页、时间或观看发生一点联系。一个段落保留一两个比喻即可，避免每句都拟人、每页都“写信”。

- 标题是这一页的观看角度，通常 6–14 字；地点名称可以另作小标签，不必把标题写成景点介绍。
- 旁注一般 30–80 字，随实际纸片面积调整；长短交替。先有具体观察，再有一两句余韵。
- 箭头旁写真正指向的对象；物件标签保持简洁。不要把所有正文排成同一种两行诗。
- “文青”不等于空泛。避免“治愈灵魂”“奔赴山海”“所有美好如期而至”等能贴在任何旅行上的句子。

| 说明式初稿 | 有观察的手帐句子 |
| --- | --- |
| 海面很亮，救生塔旁有台阶。 | 台阶收着一小片阴影，海把其余的光铺开。 |
| 金门桥是红色，海湾很宽。 | 桥把红色交给蓝天。风在卷发里停一下，又去更远的海湾。 |
| 峡谷岩层由红色转到紫色。 | 岩纹把赭红写成淡紫，光落下来，不急着离开。 |

这些例子只示范句法，不能不看照片就复用。

## 不替用户写不存在的经历

照片中可见的光、颜色、姿态可以描述；没有来源的声音、味道、温度、人物内心、时间和相处关系不能写成事实。用户提供的回忆可整理成第一人称日记，未提供时用观察式旁注或明确标注的主题创作。公开摄影样册应说明“素材演示”，不伪装成同一个人的行程。

文学比喻如“天空没有落款”属于主题文字；“那天我们在谷仓住了一晚”属于经历事实，必须有用户来源。原话引用与改写分开，日期、金额、票号不为美术效果补写。

## 排进纸页以后再读一次

中文用独立、可读的文字排版，不交给图像模型写长段。按语意断行，避免末行孤字、标点单独成行；不能为容纳文字持续缩小到难读。正文可以删短、移到旁页或换大纸片。逐页读、跨页读、整本读：是否重复句式、是否每页都写风或信、文字是否挡住人物与地标。
